# نماذج القيمة الثلاثة في Odoo: السلسلة، المتجر، الشبكة
# (Value Chain · Value Shop · Value Network)

> بناءً على ورقة **Stabell & Fjeldstad (1998)** «تكوين القيمة لتحقيق ميزة تنافسية: السلاسل
> والمتاجر والشبكات»، هناك **ثلاثة نماذج عامة لتكوين القيمة** — كل منشأة تَخلق القيمة بأحد
> هذه المنطق الثلاثة (أو مزيجٍ منها). هذه الوثيقة تشرحها بالعربية وتربط كلًّا منها
> بـ **وحدات Odoo** و**تعريف المنتج وتهيئته** و**كيفية معرفة القيمة**.
>
> مكمّلة لـ `VALUE_CONFIGURATION_METHODOLOGY.md` و `PRODUCT_VALUE_LIFECYCLE_AR.md` و
> `PRODUCT_CONFIGURATION_AR.md`.

---

## 1. الأصل: تقنيات Thompson الثلاث

كل نموذج قيمة مبنيّ على «تقنية» مختلفة لخلق القيمة:

| النموذج | التقنية | كيف تُخلَق القيمة | المنطق |
|---------|---------|-------------------|--------|
| **سلسلة القيمة** (Chain) | مترابطة طولياً | **تحويل** مدخلات → منتجات | تسلسلي |
| **متجر القيمة** (Shop) | مكثّفة | **حلّ** مشكلة فريدة للعميل | دوري/حلزوني |
| **شبكة القيمة** (Network) | وسيطة | **ربط/وساطة** بين العملاء | متوازٍ/متزامن |

---

## 2. النماذج الثلاثة بالتفصيل

### ٢.١ سلسلة القيمة (Value Chain) — «التحويل» 🏭

تَخلق القيمة بـ**تحويل المدخلات إلى منتجات**. الأنشطة الأساسية متسلسلة (مخرجات كل نشاط
مدخلات للذي يليه).

| النشاط الأساسي (الورقة) | وحدة Odoo |
|--------------------------|-----------|
| اللوجستيات الداخلية | `purchase` + `stock` (الاستلام) |
| العمليات (التصنيع) | `mrp` (أوامر التصنيع، BoM، مراكز العمل) |
| اللوجستيات الخارجية | `stock` (أوامر التسليم) |
| التسويق والمبيعات | `crm` + `sale` |
| الخدمة | `repair` / `helpdesk` |

- **محرّكات التكلفة:** الحجم (Scale) واستغلال الطاقة (Capacity utilization).
- **محرّك القيمة:** معايير شراء العميل (جودة، سعر، تسليم).
- **كيف تُعرَف القيمة:** تكلفة **تتراكم** (مكوّنات → عمالة → منتج تام) ثم هامش عند البيع.
- **مثال منتج:** كرسي مكتب مُصنَّع 🪑 — تكلفة 280 = (مواد 220 + عمالة 60)، يُباع 450.
- **تعريف المنتج:** `type=consu` (سلعة)، طريقة تقييم FIFO/AVCO، BoM للتصنيع.

> **المثال الأمثل:** مصنع، شركة توزيع، تجارة تجزئة.

### ٢.٢ متجر القيمة (Value Shop) — «حلّ المشكلة» 🧑‍⚕️

تَخلق القيمة بـ**حلّ مشكلة فريدة للعميل**. الأنشطة **دورية حلزونية** — تتكرّر حتى يُحَل
المشكل، لا خطّ إنتاج ثابت.

| النشاط الأساسي (الورقة) | وحدة Odoo |
|--------------------------|-----------|
| اكتشاف المشكلة واكتسابها | `crm` (تأهيل) / `helpdesk` (استقبال التذاكر) |
| حلّ المشكلة | `project` (المهام) / `helpdesk` (التحقيق) |
| الاختيار (القرار) | مراحل المهام / `approvals` |
| التنفيذ | `hr_timesheet` (العمل المُسلَّم) |
| التحكّم والتقييم | مراجعات `project` / `rating` / `survey` |

- **محرّك القيمة الرئيس:** **السمعة (Reputation)** — العملاء يأتون بناءً على الثقة.
- **الترابط:** **تبادلي (Reciprocal)** — حلقات مهمة ↔ مراجعة ↔ إعادة عمل.
- **كيف تُعرَف القيمة:** بالجهد المُسلَّم (ساعات/مراحل)، وتتحقّق عند تسليم الحلّ.
- **مثال منتج/خدمة:** استشارة بالساعة 🧑‍💼 — `(200−90) × الساعات`.
- **تعريف المنتج:** `type=service`، `service_type=timesheet`، `invoice_policy=delivered`،
  `service_tracking=إنشاء مشروع/مهمة`.

> **المثال الأمثل:** استشارات، طبّ، محاماة، هندسة، بحث وتطوير.

### ٢.٣ شبكة القيمة (Value Network) — «الوساطة» 🔗

تَخلق القيمة بـ**تمكين التبادل بين العملاء** (مباشر أو غير مباشر). الأنشطة **متوازية
متزامنة** — معاملات وساطة كثيرة في آنٍ واحد.

| النشاط الأساسي (الورقة) | وحدة Odoo |
|--------------------------|-----------|
| ترويج الشبكة وإدارة العقود | `website` / `sign` / `subscription` |
| تقديم الخدمة (الوساطة) | `payment` (ربط دافع↔مستفيد) / `appointment` / `event` |
| تشغيل البنية التحتية | المنصّة نفسها: `website` / `bus` / مزوّدو الدفع |

- **محرّكات القيمة والتكلفة:** الحجم واستغلال الطاقة — **القيمة تنمو بعدد المشاركين**
  (أثر الشبكة).
- **الترابط:** تجمّعي + تبادلي (Pooled & Reciprocal).
- **كيف تُعرَف القيمة:** إيراد **متكرّر** يُعرَف دورياً، ينمو بحجم الشبكة.
- **مثال منتج:** اشتراك برمجي شهري ☁️ — 100/شهر، القيمة = MRR ونموّ المشتركين.
- **تعريف المنتج:** `type=service`، `invoice_policy=order` (مدفوع مقدّماً)، اشتراك متجدّد.

> **المثال الأمثل:** البنوك، الاتصالات، التأمين، المنصّات والأسواق الإلكترونية.

## 3. جدول المقارنة الشامل (جدول ١ من الورقة)

| البُعد | السلسلة 🏭 | المتجر 🧑‍⚕️ | الشبكة 🔗 |
|--------|-----------|-------------|-----------|
| التقنية | مترابطة طولياً | مكثّفة | وسيطة |
| منطق خلق القيمة | تحويل مدخلات→منتجات | حلّ مشكلة فريدة | ربط بين العملاء |
| الأنشطة الأساسية | لوجستيات داخلية·عمليات·لوجستيات خارجية·تسويق·خدمة | اكتشاف·حلّ·اختيار·تنفيذ·تقييم | ترويج وعقود·تقديم خدمة·تشغيل بنية تحتية |
| منطق التفاعل | **تسلسلي** | **دوري حلزوني** | **متوازٍ متزامن** |
| الترابط | تجمّعي·تسلسلي | تجمّعي·تسلسلي·**تبادلي** | تجمّعي·**تبادلي** |
| محرّك التكلفة | الحجم·الطاقة | (لكل ارتباط) | الحجم·الطاقة |
| محرّك القيمة | معايير شراء العميل | **السمعة** | **حجم الشبكة** |
| نظام القيمة | سلاسل مترابطة | متاجر مُحالة | شبكات متراكبة |
| المثال | مصنع·توزيع | استشارة·طبّ·محاماة | بنك·اتصالات·منصّة |
| وحدات Odoo | purchase·mrp·stock·sale | project·hr_timesheet·helpdesk | website·payment·subscription |
| تعريف المنتج | سلعة + BoM + تقييم | خدمة + timesheet | خدمة + اشتراك |

## 4. الربط بتعريف المنتج وتهيئته

اختيار **النموذج** يحدّد **كيف تُعرَّف المنتجات وتُهيّأ** (ربط بـ
`PRODUCT_CONFIGURATION_AR.md` و `PRODUCT_VALUE_LIFECYCLE_AR.md`):

| النموذج | إعداد المنتج | التهيئة | كيف تُعرَف القيمة |
|---------|--------------|---------|-------------------|
| **سلسلة** | `type=consu`، BoM، FIFO/AVCO | متغيّرات (لون/مقاس) + `price_extra` | تراكم تكلفة → هامش |
| **متجر** | `type=service`، timesheet | حِزم خدمات/مراحل، منتجات اختيارية | بالجهد المُسلَّم، السمعة |
| **شبكة** | `type=service`، اشتراك | باقات اشتراك (Combo) متجدّدة | إيراد متكرّر، حجم الشبكة |

> أي أن **منطق القيمة** (سلسلة/متجر/شبكة) يُترجَم عملياً إلى **حقول `product.template`**:
> النوع، طريقة التقييم، سياسة الفوترة، ونمط التهيئة.

---

## 5. منشأة واحدة = عدّة نماذج (مثال Odoo نفسها)

الورقة تؤكّد أن المنشأة الواحدة قد تجمع أكثر من نموذج:

| وحدة العمل | النموذج | الدليل في Odoo |
|-----------|---------|----------------|
| عميل تصنيع/مخزون | **سلسلة** | خطّ `purchase→mrp→stock→sale` التسلسلي |
| خدمات الاستشارة/التطبيق | **متجر** | `project` + `hr_timesheet`، السمعة عبر `rating` |
| Odoo Online / المتجر / الدفع | **شبكة** | منصّة `website` تربط آلاف المستخدمين |

---

## 6. الخلاصة

- **ثلاثة نماذج لخلق القيمة:** **السلسلة** (تحويل، تسلسلي)، **المتجر** (حلّ، دوري)،
  **الشبكة** (وساطة، متوازٍ) — لكلٍّ أنشطته ومحرّكات تكلفته وقيمته (جدول ١).
- **كلٌّ يترجَم إلى Odoo:** السلسلة عبر `purchase/mrp/stock/sale`، المتجر عبر
  `project/hr_timesheet`، الشبكة عبر `website/payment/subscription`.
- **النموذج يحدّد تعريف المنتج وتهيئته:** سلعة مصنّعة بمتغيّرات (سلسلة)، خدمة بساعات
  (متجر)، اشتراك متجدّد (شبكة) — وكلّها حقول في `product.template`.
- **المنشأة قد تشغّل النماذج الثلاثة معاً**، وتعدّدية وحدات Odoo تتيح نمذجة كلٍّ منها
  وقياسه على حدة.

باختصار: «نماذج القيمة الثلاثة» هي العدسة الاستراتيجية التي تحدّد **كيف تُعرَّف المنتجات
وتُهيّأ وتُسعَّر** في Odoo — السلسلة تَبني القيمة بالتحويل، المتجر بحلّ المشكلة، والشبكة
بالوساطة.
