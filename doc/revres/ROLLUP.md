## 5. How to use (Fit-to-Standard)

- **chain** modules = the Make/Deliver standard flows; **shop** = service delivery; **network** = mediation/storefront; **support** = the shared infrastructure every workshop assumes.
- For each customer requirement: find the covering module here -> read its `out/<module>.md` brief + `metamodel/<module>.metamodel.json` -> demo live via the `run-odoo` skill -> decide **Fit** (standard) or **Gap** (configure/dev).
- `apqc` column maps each module to the customer's process taxonomy; `apqc_odoo_map.tsv` drills to activity-level (action_*).
